Open in VS Code

Connect to bench-0005-000026-press-f1 with your local VS Code Desktop over SSH. Run the commands below once, then click Launch VS Code.

Step 1
Set the PowerShell encoding to UTF-8.
$PSDefaultParameterValues['*: Encoding'] = 'utf8'
Step 2
Store the SSH certificate locally.
echo 'ssh-ed25519-cert-v01@openssh.com AAAA…' > ~/.ssh/id_ed25519-cert.pub
Step 3
Launch VS Code Desktop. It opens the bench over Remote-SSH.
