# Scripts

Operational scripts for the self-hosted Press deployment. All scripts are designed to be idempotent — safe to run multiple times.

---

## provision-server.sh

**Purpose:** Automates all 13 steps required when adding a new app server to Press.

**Run from:** press-ctrl, after creating the 3 DocType records (Server, Database Server, Proxy Server) and after Ansible `setup_server` + `setup_standalone`.

```bash
chmod +x provision-server.sh
./provision-server.sh \
  --ip 157.90.244.216 \
  --hostname u4-default.sandbox.mvpstorm.com \
  --cert-domain sandbox.mvpstorm.com \
  --press-site demo.mvpstorm.com \
  --registry 89.167.116.92:5000 \
  --team <team_hash>
```

**What it does (in order):**
1. Verify SSH access to new server
2. Deploy SSL cert (matching `--cert-domain`) to agent tls/
3. Install certbot renewal hook to keep cert synced after renewals
4. Set `press_url` in agent config.json
5. Read `agent_password` from Press DB, hash it (PBKDF2), write to agent config.json — also syncs Database Server and Proxy Server records
6. Restart agent
7. Verify `/ping` returns 200
8. Log SSL cert CN for verification
9. Add Docker insecure registry entry
10. Verify (or install) MariaDB
11. Set `team` on all three Server records
12. Check disk space (warn if >70%)
13. Reload nginx

## setup-build-worker.sh

**Purpose:** Replaces the `developer_mode=1` workaround (Lesson 16) by adding a dedicated "build" queue worker to the Frappe bench.

Without this, builds share the "default" queue with all other background jobs — a 30-minute build blocks every other operation.

**Run from:** press-ctrl, once.

```bash
chmod +x setup-build-worker.sh
./setup-build-worker.sh
```

**After running:** verify `supervisorctl status | grep build` shows RUNNING, then test a build.

## hooks/fix-letsencrypt-permissions.sh

**Purpose:** Certbot resets `/etc/letsencrypt/` permissions to 700 after every renewal. The frappe user needs 755. This post-hook restores permissions automatically.

**Deploy to press-ctrl:**
```bash
cp hooks/fix-letsencrypt-permissions.sh /etc/letsencrypt/renewal-hooks/post/
chmod +x /etc/letsencrypt/renewal-hooks/post/fix-letsencrypt-permissions.sh
certbot renew --dry-run  # verify hook runs
```

---

## hooks/sync-press-tls-records.sh

**Purpose:** When certbot renews a wildcard cert, Press TLS Certificate records in the DB still show the old expiry. This hook reads the new cert expiry and updates matching Press DB records to prevent false renewal attempts.

**Deploy to press-ctrl:**
```bash
cp hooks/sync-press-tls-records.sh /etc/letsencrypt/renewal-hooks/deploy/
chmod +x /etc/letsencrypt/renewal-hooks/deploy/sync-press-tls-records.sh
certbot renew --dry-run  # verify hook runs
```

## hooks/docker-cleanup.sh

**Purpose:** Failed Docker deploys leave containers in "Exited" state. Next deploy fails with "port already allocated." This daily cron removes all stopped containers.

**Deploy to each app server (press-f1, u4, any future servers):**
```bash
scp hooks/docker-cleanup.sh root@SERVER_IP:/etc/cron.daily/press-docker-cleanup
ssh root@SERVER_IP "chmod +x /etc/cron.daily/press-docker-cleanup"
# Test immediately:
ssh root@SERVER_IP "bash /etc/cron.daily/press-docker-cleanup"
```

**Safe:** Only removes stopped/exited containers. Never touches running containers. Only removes dangling images (no tag/reference).

## hooks/sync-sandbox-cert-to-press-f1.sh (example)

Server-specific deploy hook — auto-generated by `provision-server.sh` for each server. Lives in `/etc/letsencrypt/renewal-hooks/deploy/` on press-ctrl. Syncs cert to agent TLS dir on the corresponding server after renewal.

One hook file per server, named `sync-DOMAIN-to-IP.sh`.

## Deployment Order (new installation)

```
1. Server 1 (press-ctrl): bench install, Press app, migrate, SSL certs
2. Create DocType records in Press (Cluster, DB Server, Proxy Server, Server)
3. Run Ansible: setup_server() → setup_standalone()
4. Run: ./provision-server.sh --ip X --hostname Y ...
5. Run: ./setup-build-worker.sh  (once, on press-ctrl)
6. Deploy hooks to press-ctrl:
   cp hooks/fix-letsencrypt-permissions.sh /etc/letsencrypt/renewal-hooks/post/
   cp hooks/sync-press-tls-records.sh /etc/letsencrypt/renewal-hooks/deploy/
7. Deploy docker-cleanup to each app server
```
